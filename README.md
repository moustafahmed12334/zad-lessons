# دروس «زاد المسلم» — تحديث تلقائي من يوتيوب

هذا المستودع يبني ملف `lessons.json` الذي يقرؤه التطبيق. روبوت (GitHub Actions) يقرأ قنوات الشيوخ من يوتيوب كل يوم ويحدّث الملف وحده.

## عرضان من نفس الدروس
الملف فيه مفتاحان رئيسيان، وكلاهما مبني من نفس الدروس:

- **`shaykhs` (عرض الشيوخ):** كل شيخ بقناته كاملة — كل قوائمه ومحاضراته المنفردة في مكان واحد، وكل سلسلة معها `section` (قسمها الموضوعي) و`host` (`own` إن كانت على قناته، أو `other` مع `host_channel` إن كانت مستضافة على قناة أخرى).
- **`sections` (عرض الأقسام):** نفس الدروس موزّعة على الأقسام الموضوعية، وكل قسم يجمع كل الشيوخ معًا. الشكل هنا كما كان في النسخة الأولى، فالتطبيق القديم يظل يعمل.

```jsonc
{
  "title": "الدروس والمحاضرات",
  "version": 2,
  "updated": "2026-11-27T05:30:00Z",
  "counts": { "shaykhs": 9, "series": 185, "lessons": 4622, "section_entries": 4622 },
  "shaykhs": [
    { "id": "alaa", "name": "علاء حامد", "channel": "…", "avatar": "…",
      "counts": { "series": 62, "lessons": 1341 },
      "series": [ { "id": "PL…", "title": "…", "section": "aqeedah", "host": "own", "lessons": [ … ] } ],
      "lectures": [ … ] }
  ],
  "sections": [
    { "id": "aqeedah", "title": "العقيدة", "icon": "aqeedah",
      "shaykhs": [ { "id": "alaa", "name": "علاء حامد", "series": [ … ], "lectures": [ … ] } ] }
  ]
}
```

**الدرس الواحد يظهر مرة واحدة عند الشيخ.** لو كان الفيديو في أكثر من قائمة له، يُحفظ في القسم الأخصّ (وقسم «متنوعة» آخرًا)، فلا يتكرر الدرس في صفحة الشيخ ولا داخل القسم.

## كيف تضيف شيخًا أو سلسلة
افتح `sources.json` وعدّل، ثم احفظ (Commit). يعمل الروبوت تلقائيًا خلال دقيقتين.

- **شيخ جديد:** أضف سطرًا في `sheikhs` (لا تنسَ الفاصلة بين السطور):
  `{ "id": "mohamed", "name": "محمد فلان", "channel": "https://youtube.com/@handle" }`
  `id` حروف إنجليزية صغيرة بلا مسافات، ولا يتكرر.
- **قوائم التشغيل:** كل قائمة على القناة تصير **سلسلة**، وتُوزَّع على الأقسام بحسب كلمات عنوانها (`words` في كل قسم).
- **سلسلة على قناة أخرى:** ضع رابط القائمة في `playlists` عند الشيخ، وستُضمّ تحت اسمه ويُعلَّم عليها أنها من قناة أخرى. مثال:
  `{ "id": "sherif_ali", "name": "شريف علي", "channel": "", "playlists": ["PLPkYGF_v57Yg"] }`
  ولو للشيخ قناة وعنده معها قوائم من مكان آخر، أضف `"scan_channel": true` لتُقرأ قناته كاملة مع تلك القوائم.
- **محاضرات منفردة:** الفيديوهات التي ليست في أي قائمة (الأحدث `max_orphan_lectures`)، ولا تُحسب الفيديوهات الأقصر من `min_lecture_seconds` ثانية.
- **تغيير قسم قائمة:** افتح `report.md` وانسخ معرّف القائمة، ثم ضعه في `playlist_section`:
  `"playlist_section": { "PLxxxxxxxx": "fiqh" }`
- **استبعاد قائمة:** في بند الشيخ: `"skip": ["https://www.youtube.com/playlist?list=PLxxxx"]`
- **قوائم محددة فقط بدل كل القناة:** في بند الشيخ: `"playlists": ["رابط القائمة 1", "رابط القائمة 2"]`
- **قسم افتراضي لشيخ:** `"section": "aqeedah"` (يُستعمل لما لا تُعرف كلمات العنوان).
- **إيقاف شيخ مؤقتًا:** أضف `"enabled": false` في بنده (بياناته تبقى، ويُستبعد من البناء حتى تشيلها).

## ملاحظات
- `report.md` يُكتب مع كل تحديث: ملخص لكل شيخ، جدول كل قائمة وقسمها والقناة المستضيفة، وقائمة **تنبيهات** (قائمة فارغة، فيديوهات خاصة، قسم اختير افتراضيًا…).
- التطبيق يقرأ 5000 درس كحد أقصى حاليًا (`APP_MAX` في `build_lessons.py`). البناء يضمن البقاء تحت الحد: إن زاد الإجمالي تُقصَّر **أقدم المحاضرات المنفردة** فقط (السلاسل لا تُمسّ)، ويُكتب ذلك في «تنبيهات» `report.md`.
- الروبوت يعمل عند تعديل `sources.json` أو `build_lessons.py`، وكل يوم 3:30 صباحًا بتوقيت غرينتش.

## رابط التطبيق
بعد أول تشغيل ناجح، الرابط هو:
`https://raw.githubusercontent.com/اسم-حسابك/اسم-المستودع/main/lessons.json`
في التطبيق: المزيد ← الدروس والمحاضرات ← «ضبط الرابط» ← الصقه ← «حفظ وتحديث».
المستودع لازم يكون **Public** عشان التطبيق يقرأ الملف.

## إن ظهر خطأ
افتح تبويب **Actions** ← آخر تشغيل ← الخطوة الحمراء: الرسالة مكتوبة بالعربي (مفتاح خاطئ، خدمة غير مفعّلة، حصة منتهية، خطأ في صياغة `sources.json`...). أرسلها لي وأصلحها.

ملاحظة: إن مرّت أشهر بلا أي نشاط في المستودع قد يوقف GitHub التشغيل اليومي؛ اضغط **Run workflow** من تبويب Actions ويعود.
